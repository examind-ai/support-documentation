# Course Management

Create and manage your courses in standalone EXAMIND — names, codes, and dates.

## Accessing Courses

Click **Courses** in the left menu. From inside a course, click the course at the top of the left menu and choose **All Courses**.

### Create New Course

Click the **+ Add Course** button

### Course Settings

Input the Course Name, Course Code, and Start and End Dates.

{% hint style="info" %}
Courses are listed as either active or past courses based on the start and end dates.&#x20;
{% endhint %}
